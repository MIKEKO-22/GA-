GA BATTLE SUPPORT DUEL (VP + Chess Clock)

1. Upload index.html, manifest.webmanifest, sw.js to your GitHub Pages repository root.
2. Open the GitHub Pages URL in landscape orientation.
3. Select VP only / Clock only / Both in the center.
4. Red player display is rotated 180 degrees for face-to-face use.
5. Tap a player's clock to start it; tap the active player's clock to switch to the opponent.
6. Settings allow player names, initial minutes, increment, independent resets.
7. Saved in browser localStorage. On first use, attempts to import names, VP, and clock settings from the previous GA BATTLE SUPPORT v1 storage key (if on same origin). Previous app storage is not overwritten.

Note: Official game imagery is not included. Unofficial fan tool.
