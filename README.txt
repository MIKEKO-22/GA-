GA BATTLE SUPPORT v1.0 (非公式ファンツール)

使い方：
1. index.html をPCブラウザで開いて試せます。
2. スマホ配布：このフォルダ内の3ファイルをGitHub Pages等のHTTPS静的サイトに公開してください。
3. 公開URLをスマホで開き、共有→ホーム画面に追加。
4. データは各端末のブラウザ内に保存されます。別端末との同期はありません。

注意：
・時計は同一端末で交互にタップして使います。
・TLはフェーズ1・2、各10ラウンド。TL20を超える場合はフェーズ2のTL10に仮固定する仕様です（超過分の詳細裁定は今後改善）。
・同マスのユニットは上矢印／下矢印で順番を調整できます。
・時計を再設定すると持ち時間が初期化されます。
・インクリメントは手番交代時に、それまで動いていた側に加算されます。
・公開前にiPhone/Androidの実機で動作確認を推奨します。
